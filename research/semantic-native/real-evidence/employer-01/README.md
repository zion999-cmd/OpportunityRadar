# Employer Evidence 01 — Patch product-design situation

## Scope

This directory is an employer-side evidence acquisition artifact for the Semantic Native real-evidence experiment. It does not evaluate recruiting quality, describe any person, or attempt matching.

The admitted situation is Patch's public search for a Product Designer to shape product surfaces for an AI-native environmental-markets service. The hiring page is read together with three first-party pages describing the same operating model and platform context. These pages were retrieved on 2026-09-07.

## Acquisition method

- Public-web search was performed independently of the Public Experience Pool.
- Eleven public pages were inspected, covering eight distinct employer hiring situations and several contextual sources for the admitted situation.
- The comparison set was intentionally varied: climate science, product design, lifecycle assessment, revenue operations, solutions consulting, sustainability, hardware engineering, and facilities/operations.
- Rejections were made only for methodological evidence-quality reasons.
- The admitted source was preferred because the employer-authored hiring expression is unusually specific about present workflows, organizational interfaces, intended change, early outcomes, and working constraints; contemporaneous first-party context corroborates the same situation.

## Files

- `acquisition-candidates.ndjson` — one decision record for every inspected page
- `sources.md` — Layer 1 source trace and provenance ledger
- `raw-employer-expression.md` — Layer 2, minimally transformed employer expression
- `evidence-reconstruction.md` — Layer 3, epistemically labeled reconstruction

## Boundaries observed

No P001–P012 material, recruiting-POC fixture, synthetic candidate, matching/discovery output, Semantic Completion output, relationship artifact, or content within `research/semantic-native/real-evidence/pilot-01/sources/` was inspected. No Hermes or matching process was run. No existing Semantic Native code was modified.
